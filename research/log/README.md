# Research log

One file per attempted iteration of the research loop, **including failures and
inconclusive attempts**. Agents read this directory before choosing an idea so that
nobody repeats a dead end without a new angle.

File name: `YYYY-MM-DD-<slug>.md`, created from `TEMPLATE.md` at the start of an
iteration and completed at the end. Keep entries factual and short; paste the
harness's speedup lines verbatim and name the result file under `../results/`.
